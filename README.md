# CryptoX

A **cryptocurrency showcase demo app** built in **Swift** and **UIKit** following the **MVVM** architecture. Browse live coin prices, view detailed charts, and simulate a basic purchase flow.

---

## 🚀 Features

* 📋 **Coin List**: Displays a list of top cryptocurrencies with current prices and 24h change.
* 📈 **Coin Detail**: Detailed view for each coin with an interactive price chart (using dummy data).
* 💸 **Dummy Purchase Flow**: Simulate buying coins with a mock transaction screen.
* 🏗️ **MVVM Architecture**: Clear separation of Model, View, and ViewModel.
* 🎨 **UIKit UI**: Custom table and collection views, programmatic layout.
* 🔄 **Async/Await**: Modern concurrency for networking and data updates.

---

## 🛠️ Tech Stack

* **Language:** Swift 5+
* **UI Framework:** UIKit
* **Architecture:** MVVM
* **Networking:** URLSession (async/await)
* **Charts:** Recharts (or your charting library of choice)

---



## 🎬 Usage

1. **Launch the app** to see the list of cryptocurrencies.
2. **Pull-to-refresh** to update live prices.
3. **Tap a coin** to view its detail screen with a price chart.
4. **Tap “Buy”** to open the dummy purchase flow, enter an amount, and confirm.
